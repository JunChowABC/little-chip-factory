# 小小薯片厂 · Little Chip Factory

[点击开始游戏](https://junchowabc.github.io/little-chip-factory/)

一款明亮卡通风格的竖屏工厂经营小游戏：收获土豆，切片、油炸、包装并出货，升级设备和雇佣帮手。

电脑使用鼠标、手机使用触屏拖动左下摇杆。靠近农田、投料点和取货点自动交接物料。进度自动保存在当前浏览器；清除网站数据会删除存档。请使用手机竖屏游玩。
